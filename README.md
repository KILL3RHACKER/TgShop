# Telegram Shop Bot (Aiogram 3.x + Docker)

Полнофункциональный магазин в Telegram на базе **Aiogram 3.x**, **SQLAlchemy 2.0 (Async)**, **PostgreSQL**, **Redis** и крипто-генерации адресов TRON (TRX/USDT TRC-20).

## 🚀 Возможности
- 🛍 **Каталог товаров**: Категории -> Список товаров -> Карточка товара -> Покупка в 1 клик с баланса.
- 👤 **Профиль & Баланс**:
  - Генерация персонального TRX/USDT TRC-20 адреса для каждого пользователя (чистый Python, `secp256k1`, без сторонних платных API и без комиссий).
  - Реферальная система с персональной ссылкой (`?start=ref_ID`) и автоматическими процентными начислениями с пополнений.
- 💳 **Тикеты пополнения (15 минут)**:
  - Создание тикета на пополнение с суммой и адресом.
  - Автоматическая экспирация тикета через 15 минут с уведомлением пользователя.
- ⚙️ **Админ-меню**:
  - Уведомление админа о новом тикете с кнопками `[Подтвердить]` / `[Отклонить]`.
  - Просмотр очереди активных тикетов.
  - Начисление баланса пользователю и реферального бонуса пригласителю при подтверждении.

## 🛠 Быстрый старт (Docker Compose)

### 1. Клонирование и настройка окружения
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd tg_shop_bot
cp .env.example .env
```

Заполните переменные в `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
ADMIN_ID=123456789
DATABASE_URL=postgresql+asyncpg://postgres:postgrespassword@db:5432/shop_bot
REDIS_URL=redis://redis:6379/0
REFERRAL_PERCENT=5.0
TICKET_EXPIRE_MINUTES=15
```

### 2. Запуск контейнеров
```bash
docker compose up -d --build
```

### 3. Просмотр логов
```bash
docker compose logs -f bot
```

## 🌐 Веб-панель администратора (Web Control Panel)

Управление складом, тикетами, товарами и пользователями доступно через современный веб-интерфейс:
- **URL**: `http://localhost:8000`
- **Логин по умолчанию**: `admin`
- **Пароль по умолчанию**: `admin123` (настраивается в `.env` через `ADMIN_WEB_USER` и `ADMIN_WEB_PASSWORD`)

### Возможности веб-панели:
- 📊 **Дашборд**: статистика пользователей, общего оборота, остатков на складе и недавних тикетов.
- 📦 **Склад аккаунтов (Инвентарь)**:
  - Пакетная загрузка через **ZIP-архив** (распаковка и парсинг `.txt` файлов с аккаунтами формата `NAME SURNAME, DD/MM`).
  - Быстрое добавление списком через текстовое поле.
  - Удаление: одиночное, массовое через чекбоксы («Выбрать все») и удаление по вставленному списку строк.
  - Фильтры по товару, статусу (свободен / продан) и текстовый поиск.
- 🎫 **Тикеты пополнения**:
  - Просмотр всех заявок, фильтрация по статусам (Ожидают, Одобрены, Отклонены).
  - Одобрение и отклонение в 1 клик с моментальным обновлением баланса, начислением реферального бонуса и Telegram-уведомлениями.
- 🏷 **Товары и Категории**:
  - Полный CRUD для категорий и товаров (изменение цен, описаний, отслеживание количества на складе).
- 👥 **Пользователи**:
  - Список клиентов, балансы, Tron-адреса, рефералы и ручная корректировка баланса.

## 💻 Локальный запуск (без Docker)

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Убедитесь, что запущен локальный Redis и PostgreSQL (или переключите `DATABASE_URL` на `sqlite+aiosqlite:///bot.db`).
3. Запустите бота:
   ```bash
   python -m bot.main
   ```
4. Запустите веб-панель управления:
   ```bash
   uvicorn web.main:app --host 0.0.0.0 --port 8000
   ```
